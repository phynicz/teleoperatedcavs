# Teleoperated Connected and Autonomous Vehicles
This is the artifact repository for the paper "“Right now, it’s the wild west”: Qualitative Insights into the Security, Privacy, and Safety of Teleoperated Connected and Autonomous Vehicles (CAVs)". This repository contains the following:

### Codebook
+ The codebook was developed during our qualitative analysis. This codebook contains primary and secondary-level codings, as well as a description and an example for each code.
